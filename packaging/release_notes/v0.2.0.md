# Blind accessibility beta 0.2.0

This is a beta of the blind accessibility version of Luigi's Mansion Recompiled. No game data is included: you need your own USA disc image. Unzip the folder anywhere you can write to, then run LuigisMansionRecomp.exe.

- Speech through NVDA and other screen readers, on automatically.
- Spoken menus, dialogue and choices, with each item's position.
- Go to menu with pathfinding: press the left stick in.
- Sounds that lead you to objects, ghosts and Toads, and warn of banana peels.
- An Accessibility tab in the options menu, with an audio cue glossary.
- The game pauses while the Go to and options menus are open.
- Spoken update notices.

Windows only for now. The game's own text is spoken for the USA version.
