## Fixed
- **The first key door (Parlor) and the PAL base (#2, #10):** the game had 1 MB less memory than on a console. At the first-key cutscene it ran out and overwrote system memory. On the European version that broke the frame timer, so the game ran far too fast or dropped to around 10 fps; the USA version was affected too. The memory layout now matches the console, and safety checks catch and log any such overwrite.
- **Original 30 fps (#13):** cutscenes, starting with the intro's map close-up, ran slower than real time and the sound drifted out of sync. The renderer was doing far more work per frame than needed at 30 fps; it now holds a steady 30 with the sound in sync, and the picture is unchanged. The Parlor after the key door is also back to a steady 30.
- **Shader preparation on every start (#6):**
  - Starting with the shaders already cached is faster: about 0.5 s with default settings and 1.3-1.9 s with Enhanced lighting Ultra on a fast PC.
  - The game still waits until every shader is ready, so nothing stutters.
  - Shaders for other graphics settings are no longer deleted from the cache.
  - The message now says whether it is loading or compiling, and why.
- **After a crash or a forced close:** the next start no longer recompiles every shader, which could take several minutes with Enhanced lighting.
- **Rumble (#12):** rumble is now re-sent to the controller assigned to each port, and retried if the controller refuses it. F1 > Controls > Sticks, triggers & rumble > "Test rumble" now tells you whether the controller accepted it. If rumble still doesn't work for you, please report what that button says.
- **Windows user names with accents or other non-English letters:** the game no longer crashes at startup.
- **settings.ini saved with a byte-order mark:** the first section is no longer lost.
- **Linux on systems without full graphics support** (OpenGL ES fallback): no longer crashes when the GPU keep-warm starts.

## Known issues
